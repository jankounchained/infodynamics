<objective>
Close the Phase 5 UAT blocker (test 3): CI on ubuntu-latest fails `test_text_signals_match_golden_baseline` and `test_multiscale_structure_matches_golden_baseline` in `tests/test_golden_baseline.py`, while both pass locally on macOS. The diagnosis (`.planning/debug/golden-baseline-ci-drift.md`) is CONFIRMED and unambiguous: these two tests compare float32-precision, sentence-transformer-derived data (embeddings → cosine-similarity SSMs → resonance/novelty/transience signals and SSM-derived descriptors) using `atol=1e-8`, a float64-grade absolute tolerance. float32 machine epsilon is ~1.19e-7; macOS (Accelerate/vecLib BLAS, used to capture the baseline) and Linux CI (OpenBLAS/manylinux BLAS) reorder non-associative float32 summations and produce mathematically-equivalent but not bit-identical results differing by up to ~1 ULP (every CI diff was 6e-8..1.6e-7). That exceeds `atol=1e-8` on near-zero/near-one elements where the atol term dominates, so `np.allclose` fails the whole array.

This was empirically proven to be NOT a v0.5 refactor regression: recomputing on the same macOS machine that holds the checked-in baseline reproduces it with 0/27 array mismatches, even with materially newer numpy/scikit-learn/torch/sentence-transformers. The cross-platform gap was structurally guaranteed to surface the first time the suite ran on Linux — which is this phase (CI was added in 05-03).

The fix is scoped to the test's tolerance/comparison strategy and its documentation ONLY. It MUST NOT touch production analysis code (`metrics.py`, `scalogram.py`, `time_series.py`, `text/embedding.py`) — the diagnosis proved that code is correct and platform-invariant at the algorithm level; only raw float32 bit-reproducibility across BLAS backends is not guaranteed. Upcasting embeddings to float64 would change the golden baseline itself and every downstream output, violating the milestone's hard constraint ("Refactor, not rewrite: no change to the numerical output of surviving analysis code"), so it is out of scope.

Purpose: Make QA-01 ("no numerical drift") cross-platform-honest — same-platform bit-determinism PLUS a bounded, still-meaningful float32 tolerance band — so QA-04's full suite goes green on CI (Linux), not just locally (macOS).
Output: A tolerance-policy update + documentation in `tests/test_golden_baseline.py`.
</objective>
