<objective>
Decouple the composite core estimators from text (CORE-02). Strip `InfoDynamics` and `MultiscaleInfoDynamics` of their `segment()`/`Encoder.encode()` calls and all text-only constructor params so `fit(X)`/`transform(X)` accept only numeric embeddings (ndarray). Converge their outputs onto the D-03 array-return convention: `InfoDynamics.transform` returns a `(n_chunks, 3)` novelty/transience/resonance array with the rich dict on `self.signal_`; `MultiscaleInfoDynamics.transform` returns the scalogram matrix with the four-part structure dict on `self.result_`. Removing the text imports also resolves the interim exception Phase 2 deliberately left in `pipeline.py`.

Purpose: CORE-02 is the milestone's substantive rewrite — the core analysis pipeline must be modality-agnostic (ndarray in, signals out) so it composes as a real Pipeline step downstream of any encoder. The text on-ramp logic being removed here is relocated verbatim into the Plan 05 wrappers.
Output: `infodynamics/pipeline.py` with two ndarray-only, Pipeline-legal composite estimators and zero text imports.
</objective>
